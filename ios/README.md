# ios/

Native iOS Swift app for SnoreGuard. Empty stub for now — the Xcode project,
SwiftUI sources, and `Info.plist` land in a follow-up branch (`ios-record-tab`,
phase 2 in `docs/NATIVE_IOS_PORT_PLAN.md`).

The web app at the repo root (`src/`) is the visual product spec — see
`docs/PRODUCT_SPEC.md` for the feature parity matrix that this folder must
implement.
