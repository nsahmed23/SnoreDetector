## 2025-03-05 - Avoid Unnecessary Web Audio API Teardowns in useEffect and Apply Loop Fusion
**Learning:** In React components that manage high-frequency audio processing loops (like `requestAnimationFrame`), including derived or high-frequency mutable state variables (e.g. `isCurrentlySnoring`) in a `useEffect` dependency array will cause the entire Web Audio API stream (`getUserMedia`, `AudioContext`, tracking loops) to tear down and restart every time the state changes. Furthermore, multiple iterations over frequency data arrays (`dataArray`) in tight loops like `requestAnimationFrame` cause significant CPU overhead.
**Action:** Use a `useRef` to track high-frequency local state inside closures rather than relying on state variables in the `useEffect` dependencies. Also, merge multiple iterations over the same data structures (loop fusion) to reduce repetitive computations and maintain 60fps performance without audio artifacts or tearing.
