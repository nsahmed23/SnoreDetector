
## 2024-06-13 - [Frontend Audio Loop Fusion & React.memo Optimization]
**Learning:** High-frequency audio processing loops (like inside `useAudioMonitor.ts`) and React hooks handling fast mutable state can cause significant performance degradation. Unnecessary teardowns and restarts of the Web Audio API stream triggered by tracking closures in dependency arrays, and rendering unmodified React components within 60fps cycles are anti-patterns. Fusing loops inside requestAnimationFrame cycles and avoiding React.memo on components taking high-frequency changing props (while using them properly on child components) resolves these bottlenecks.
**Action:** When working on real-time audio components that run inside `requestAnimationFrame`, always use `useRef` for tracking mutable state internally, fuse looping operations over the same data source, and ensure that only components displaying that rapid data re-render, by wrapping side-by-side or infrequently updated components in `React.memo()`.
