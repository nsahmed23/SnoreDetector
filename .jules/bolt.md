## 2024-05-15 - [React Audio Loop Performance Optimization]
**Learning:** High-frequency state updates inside `requestAnimationFrame` loops (like a 60fps audio volume monitor) cause continuous and expensive cascading re-renders in React component trees if child components are not memoized. Furthermore, avoiding redundant loops over large audio buffer arrays (like `dataArray`) by using loop fusion dramatically decreases the CPU cost per frame and reduces the likelihood of jank.
**Action:** When working with fast-updating parent components (e.g., audio visualizations driven by requestAnimationFrame), proactively wrap static or infrequently updating child components in `React.memo()`. Always merge multiple iteration passes over arrays (loop fusion) inside high-frequency execution loops.
