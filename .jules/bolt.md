## 2024-05-18 - [Optimized 60fps Audio Processing Loop and Component Rendering]
**Learning:** High-frequency `requestAnimationFrame` loops (like those processing 60fps audio data) can easily bottleneck the main thread if they trigger unnecessary component re-renders or perform unoptimized array operations. Even if a component's props don't change frequently, if its parent re-renders at 60fps, it will also re-render unless memoized. Furthermore, multiple iterations over large typed arrays inside these fast loops compound CPU usage.
**Action:** Always wrap static or infrequently updating children of fast-updating parent components with `React.memo()`. Also, manually apply loop fusion (combining multiple loops over the same array) in performance-critical JavaScript/TypeScript paths, particularly within `requestAnimationFrame` callbacks, to minimize array traversal overhead.
