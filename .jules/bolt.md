## 2024-05-24 - Frontend 60fps Loop Fusion & React Effects
**Learning:** High-frequency state changes (like detecting a snore in a 60fps `requestAnimationFrame` loop) inside a `useEffect` will tear down and restart expensive external resources (like the Web Audio API MediaStream) if added to the effect's dependency array. Additionally, multiple passes over FFT data arrays (e.g., getting average, then finding low vs high frequency distributions) in the 60fps loop adds unnecessary CPU overhead.
**Action:** Always use `useRef` to track high-frequency state that must be mutated within an audio/animation loop closure without triggering the effect to re-run. Synchronously update the ref along with the React state setter. Always apply loop fusion to combine multiple array iterations into a single loop inside `requestAnimationFrame` cycles to preserve cache locality and CPU cycles.
