## 2025-03-01 - Avoid useAudioMonitor stream tearing by decoupling mutable state from useEffect deps
**Learning:** In high-frequency 60fps loops (e.g., `requestAnimationFrame` for Web Audio tracking), managing fast-changing state like `isCurrentlySnoring` inside a React `useEffect` closure can cause severe performance issues. If the state is included in the dependency array, it triggers costly cascading teardowns and restarts of `navigator.mediaDevices.getUserMedia` streams every time snoring starts or stops.
**Action:** Decouple the state update by using a `useRef` (e.g. `isCurrentlySnoringRef`) to track state synchronously inside the loop. Update the ref alongside the React state setter to prevent the closure from becoming stale, and remove the state from the `useEffect` dependency array. Additionally, apply loop fusion to combine multiple array iterations inside the 60fps update cycle to boost performance and reduce JS overhead.
