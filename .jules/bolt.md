## 2023-10-27 - High-frequency React hooks and Web Audio API performance
**Learning:** Including state variables that update during a high-frequency `requestAnimationFrame` loop (like `isCurrentlySnoring`) in a `useEffect` dependency array that manages a Web Audio API stream causes the stream to be continuously torn down and restarted. This results in severe performance degradation and audio stuttering. Additionally, running multiple consecutive iterations over the same audio buffer (`dataArray`) in a 60fps loop adds unnecessary CPU overhead.
**Action:** Use a `useRef` to track mutable state that is accessed inside closures within high-frequency loops, avoiding unnecessary `useEffect` re-renders and stream restarts. Apply loop fusion to combine multiple array passes into a single iteration where possible.
