## 2024-05-18 - 60fps Rendering Bottleneck & Audio Processing
**Learning:** The frontend relies heavily on a 60fps `requestAnimationFrame` loop in `useAudioMonitor.ts` to process audio data and update the `volume` state in `RecordTab`. This causes frequent re-renders of the parent component, leading to unnecessary cascading re-renders of its children. Furthermore, separating audio array processing logic into multiple loops inside this high-frequency loop can create a performance bottleneck.
**Action:** When working with fast-updating components (like those visualizing audio at 60fps), ensure that static or infrequently updating child components are wrapped in `React.memo()`. For the high-frequency audio processing loop, always apply loop fusion (merging multiple passes over data arrays into a single pass) to avoid redundant iterations and minimize computational overhead.
