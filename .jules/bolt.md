## 2024-05-19 - AudioContext Teardowns due to React Hooks
**Learning:** Including high-frequency mutating state (like `isCurrentlySnoring` tracking true/false multiple times a second) in the `useEffect` dependency array that initializes the Web Audio API causes the entire audio pipeline (`MediaStream`, `AudioContext`, `AnalyserNode`) to be torn down and recreated every time the state changes. This is a massive performance bottleneck, especially in a 60fps `requestAnimationFrame` loop.
**Action:** Always decouple fast-updating state from expensive initialization logic. Use a `useRef` to track the state synchronously within the loop (e.g., `isCurrentlySnoringRef.current`) and trigger the React state setter for UI updates without letting the state value re-run the `useEffect`.
