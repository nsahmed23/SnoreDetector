
## 2023-11-09 - [Performance Optimization: Loop Fusion in Audio Processing Hot Paths]
**Learning:** The application heavily relies on high-frequency audio processing loops, specifically running at 60fps in the frontend (`useAudioMonitor.ts`) and within the Rust core audio detector (`detector.rs`). These paths process arrays iteratively (e.g., FFT frequency bins). It was discovered that separating operations into multiple loops (e.g., one to calculate total sum/magnitude, another to calculate frequency bands) was adding redundant array traversals in these critical loops.
**Action:** Used loop fusion in both Rust and TypeScript to combine array traversals. Calculate sums, frequency band accumulations, and other scalar operations in a single pass. This improves CPU cache locality and avoids O(N) redundant iteration overhead per frame. Next time, always check inside `requestAnimationFrame` or `push_frame` callbacks for separated loops over the same underlying data structure.
