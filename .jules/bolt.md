## 2025-03-04 - [Optimize 60fps audio rendering loop]
**Learning:** High-frequency `requestAnimationFrame` loops (like processing audio data arrays 60 times a second) are extremely sensitive to performance bottlenecks. Two common anti-patterns emerged: 1) Executing multiple O(n) passes over the same data array (e.g., separate loops for total sum and frequency bands), and 2) Passing fast-updating state (like live audio volume) to parent components, causing expensive, deep re-renders of static children components.
**Action:** Always apply "loop fusion" inside high-frequency audio processing loops to compute multiple metrics in a single pass over arrays. Additionally, heavily utilize `React.memo()` on static or infrequently updating child components (like `LiveStatsCard`) that sit alongside 60fps fast-updating components to prevent unnecessary rendering overhead.
