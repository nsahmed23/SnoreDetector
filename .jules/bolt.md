## 2025-05-15 - React audio loop optimizations
**Learning:** High-frequency `requestAnimationFrame` loops in React can cause severe performance degradation if they trigger cascading re-renders in un-memoized child components, or if they rely on state variables in `useEffect` dependency arrays that trigger teardowns of expensive objects like `MediaStream`. Furthermore, doing multiple passes over data arrays (like FFT frequency data) within a 60fps loop adds unnecessary overhead.
**Action:** Always apply loop fusion to combine multiple passes over data arrays in hot paths. Track rapidly changing values with a `useRef` updated synchronously alongside `setState` inside the loop to avoid placing them in `useEffect` dependency arrays. Lastly, wrap static or infrequently updating child components of rapidly updating parents in `React.memo()`.
