## 2026-06-24 - [Avoid Stream Teardown & Loop Fusion in high-frequency audio loop]
**Learning:** In `useAudioMonitor.ts`, referencing state variables (like `isCurrentlySnoring`) in the `useEffect` dependency array that are meant for use inside a fast 60fps `requestAnimationFrame` loop creates a severe performance bottleneck. It causes the entire Web Audio API stream to tear down and restart frequently. Additionally, multiple passes over `dataArray` to calculate `avg` and the high/low bands causes unnecessary overhead.
**Action:** Use a `useRef` variable alongside state for values accessed frequently within closures (like `isCurrentlySnoringRef`), so they can be read and updated without triggering effect re-evaluation. Use Loop Fusion to combine multiple iterations over high-frequency FFT `dataArray` into a single loop.
