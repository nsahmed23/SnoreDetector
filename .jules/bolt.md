## 2025-02-20 - [Frontend] Prevent Web Audio API Teardowns & Optimize Render Loop
**Learning:** In high-frequency React hooks relying on `requestAnimationFrame` (like `useAudioMonitor.ts`), placing rapidly-changing state variables (like `isCurrentlySnoring`) in the `useEffect` dependency array triggers full teardowns and restatements of underlying expensive resources like the Web Audio API (`AudioContext`, `MediaStream`). Additionally, performing multiple loops over frequency bin arrays at 60fps creates unnecessary CPU overhead.
**Action:** Use `useRef` to track fast-mutating state synchronously alongside React state setters inside the animation loop. Apply "loop fusion" to consolidate multiple passes over data arrays into single iterations to improve cache locality and lower computation time in the `requestAnimationFrame` loop.
